จุดพิมพ์ครัว

เพิ่มเครื่องพิมพ์ได้หลายเครื่อง แล้วเลือกว่าแต่ละเครื่องพิมพ์เฉพาะเมนูหมวดไหน เช่น เครื่องในครัวพิมพ์กับข้าว เครื่องหน้าบาร์พิมพ์เครื่องดื่ม ออเดอร์เดียวจะถูกแยกพิมพ์ไปตามเครื่องที่ถูกต้องอัตโนมัติ

กำลังเช็คสถานะตัวเชื่อมเครื่องพิมพ์...

ติดตั้งตัวเชื่อมเครื่องพิมพ์ (ครั้งแรกเท่านั้น)

เว็บนี้รันอยู่บนคลาวด์ ยิงคำสั่งพิมพ์ตรงเข้าเครื่องพิมพ์ในร้านไม่ได้โดยตรง ต้องใช้โปรแกรมตัวเชื่อม (print agent) รันอยู่บนคอมพิวเตอร์เครื่องหนึ่งที่ต่อ WiFi/LAN วงเดียวกับเครื่องพิมพ์ทุกเครื่อง คอยดึงออเดอร์ใหม่มาพิมพ์ให้อัตโนมัติ แล้วรายงานสถานะเชื่อมต่อกลับมาที่หน้านี้ให้เห็นแบบเรียลไทม์

⬇️ ดาวน์โหลดตัวเชื่อมเครื่องพิมพ์ (print-agent.zip)

  1. เพิ่มเครื่องพิมพ์และตั้งค่า IP ด้านบนแล้วกดบันทึกก่อน
  2. เอาไฟล์ที่ดาวน์โหลดไปแตกไว้บนคอมพิวเตอร์ที่ต่อ WiFi/LAN วงเดียวกับเครื่องพิมพ์ (ต้องลง Node.js ไว้ก่อน)
  3. เปิด Terminal ในโฟลเดอร์นั้น รัน npm install แล้วรัน npm start
  4. โปรแกรมจะดึงรายชื่อเครื่องพิมพ์/IP/ขนาดกระดาษ/ชื่อร้านจากที่ตั้งไว้ด้านบนเองอัตโนมัติ เปิดทิ้งไว้ตลอดเวลาร้านเปิด
